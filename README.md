## 📌 Overview

A retro arcade car driving game built with **JavaScript** and **HTML5 Canvas**. Steer your vehicle along a high-speed motorway, avoid incoming traffic obstacles, and set the highest distance score.

---

## ✨ Key Features

- **Keyboard Steering Controls:** Smooth left, right, acceleration, and brake keyboard controls.
- **Dynamic Obstacle Spawning:** Procedurally generated oncoming vehicles with varying speeds.
- **Bounding-Box Collision Detection:** Real-time geometric intersection checking triggering game over states.
- **Score & Speed Progression:** Dynamic scoring engine that increases game difficulty as speed multiplies.

---

## 💻 Tech Stack & Architecture

- **Game Engine:** Vanilla JavaScript, HTML5 Canvas Rendering Loop
- **Physics:** AABB Collision Detection, Velocity/Acceleration Vectors
